# 决策记录

## 2026-08-09：通用网页媒体导入器只处理直连媒体

- 决定：建立独立 `web-media-importer`，由用户点击按钮或右键菜单触发；不在后台自动扫描网页。
- 决定：纯核心只接受直接 HTTP(S) 图片/视频，稳定去重并限制单批 80 项；`blob:`、`data:`、
  HLS/DASH 清单、DRM/加密或未知源明确跳过。
- 决定：后台逐项串行使用 Chrome Downloads 缓存，再调用 Eagle 公开 `addFromPath`；不修改
  `app.asar`、`.library`，不读取 NAS 路径或插件业务状态。
- 决定：Eagle API `success` 仅记录为 `accepted`，不宣称已在界面可见；失败项持久化并可重试。
- 决定：媒体下载仍使用页面原始直连地址，但写入 Eagle 的来源文字会移除常见 token、签名、凭证、
  过期参数和追踪参数，避免共享 Library 扩散临时访问凭据。
- 决定：只在 `accepted` 后安排缓存清理，延迟至少 24 小时，降低慢磁盘/NAS 导入期间源文件被
  过早删除的风险。
- 决定：Instagram、小红书专用页面识别继续由各自扩展负责；通用入口不得宣传为“所有网页、
  所有视频都能下载”。

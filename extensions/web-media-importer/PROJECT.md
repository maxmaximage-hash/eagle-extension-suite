# 项目档案

- 项目名称：网页媒体保存至 Eagle
- 项目类型：Chrome 扩展 / Eagle 外部导入工具
- 所属产品：EAGLE 扩展
- 当前源码版本：`1.0.0`
- 插件名称：`网页媒体保存至 Eagle`
- 标准源码：本目录
- 发布目录：仓库根 `releases/网页媒体保存至Eagle-Stable/eagle-web-media-importer`

## 产品目标

用户显式触发后，将当前页面已经加载且具有直连地址的图片/视频安全交给指定 Eagle 普通文件夹，
同时保留来源、去重、串行队列、失败原因和重试能力。

## 边界

- 通用入口不等于站点破解器；不支持流清单、DRM、浏览器临时对象或权限绕过。
- Instagram、小红书的站点专用单帖能力继续由其各自扩展维护。
- 不修改 Eagle 宿主或 Library，不持有 NAS 路径，不读取排序/标签/发布状态。

# 决策记录

## 2026-08-01：sharp 直接生产依赖升级至 0.35.3

- 决定：Eagle 插件将 `sharp` 精确锁定为 0.35.3，不调整水印、隐私打码、字体和导出业务 API。
- 原因：旧直接依赖 0.32.6 命中 GHSA-f88m-g3jw-g9cj 高危通告；0.35.3 是本次审计建议的最低修复版本。
- 验证：完整自动测试、隐私构建、插件打包，以及根项目和 Eagle 插件的生产依赖审计均为门禁；真实 Eagle 冒烟另需批准。
- 回滚：保留 1.2.6 发行证据和安装包；若 1.2.7 冒烟失败，恢复 1.2.6，不回退到含高危依赖的更早版本。

## 2026-08-01：根开发与线上发布工具链锁定 wrangler 4.118.0

- 决定：根项目将开发依赖 `wrangler` 精确锁定为 4.118.0；Eagle 插件生产依赖继续保持 `sharp` 0.35.3。
- 原因：旧 `wrangler` 4.107.0 经 `miniflare` 间接携带 `sharp` 小于 0.35 的高危链路。
- 验证：总管在同一源码目录执行根 `npm audit --json`，开发依赖在内均为 0 漏洞；Eagle 插件 `npm audit --omit=dev --json` 为 0 漏洞。
- 边界：此项只更新开发/线上发布工具链锁文件，不触发 Eagle 安装、发布、真实资料库或线上数据操作。

## 2026-08-01：字体目录按本机发现，发布包不绑定开发者目录

- 决定：随包 `catalog.js` 仅保留分类与 PostScript 身份参考，不能作为其他电脑的可用字体清单；Eagle 运行时优先通过 macOS 字体清单发现当前用户和系统实际存在的文件。
- 原因：用户字体位于每台 Mac 的不同主目录，静态绝对路径会导致字体预览和真实导出不一致。
- 影响：已保存但缺失的字体会降级为可用兜底字体；真实 Eagle 冒烟仍需确认提示与实际导出结果。水印、打码、文字标注和本地导出无需 API Key；Cloudflare 发布仅使用本机 Wrangler 登录或环境变量，密钥不写入仓库。
- 回滚：保留 1.2.5 安装包作为已安装基线；若 1.2.6 真实 Eagle 冒烟失败，恢复 1.2.5 包并保留本轮 SHA-256 证据。

## 2026-07-26：水印与隐私导出消费统一的共享压缩契约

- Eagle 的水印工作台和隐私工作台共同消费 `gravity-quick-export/1.0.1` 与 `gravity-watermark-editor/1.1.2`，vendor 必须与独立共享模块逐文件一致。
- 体积模式只由目标字节上限驱动，不读取隐藏的质量滑杆值；最终落盘文件超过 `目标 MB × 1,000,000` 字节即为失败。
- Publisher 每处理一项都等待异步进度回调，包括源文件缺失的失败项，保证 UI 可以实际绘制 `1/N ... N/N`。

## 2026-07-18：线上发布数据与源码分离

- 决定：`cloudflare-pages/public/images`、`gallery.json` 和实际发布内容移出源码项目，统一存放于 `~/引力环球/Eagle线上发布数据`。
- 原因：这些文件是运行和业务发布数据，总量约 1.6 GB，不属于版本化源码。
- 影响：插件配置中的 `pagesRoot` 和本机默认路径更新；新源码只保留页面程序与 `_headers` 模板。
- 未来复查条件：发布数据迁入 NAS 或其他正式数据服务时。

## 2026-07-18：MAX Publisher 保持独立 Eagle 扩展

- 决定：线上展示、水印、打码、字体和发布作为 Eagle 产品体验保留在本扩展；通用算法通过版本化共享模块提供。
- 原因：Eagle 选择项、插件窗口、资料库和发布流程属于明确宿主边界。
- 影响：MORROW 和未来产品只能接入共享模块，不能引用本插件内部源码。
- 未来复查条件：某项能力出现独立产品级用户和发布生命周期时。

# Eagle 工作台

Eagle 工作台是扩展功能的统一入口面板。每张卡片先显示该产品的基本功能，再显示当前版本的重要修复记录。交付文案在工作台内独立扫描、套用模板和复制，地点标签仍从独立标签面板进入。

## 设计边界

- 用户界面只显示两段式产品版本 `major.minor`；minor 只从 `0` 到 `9`，例如 `1.9` 之后进入 `2.0`，不会出现 `1.11`，也不会把三段式技术版本显示给用户。
- 工作台自身的 manifest、package、Eagle 安装确认和用户界面统一使用两段式 `2.1`；不会在任何工作台位置显示三段式版本。
- 工作台保留排序和文件名产品的版本记录，但不提供它们的执行入口。相关操作只在 Eagle 原生排列面板中进行。
- 交付文案生成是工作台独立产品，支持多个交付档位模板、直属子文件夹扫描、实际交付统计、占位符填充、夸克链接编辑和复制。
- 地点标签从工作台请求打开独立标签面板；工作台不自动扫描整个 Library，不自动改名、不写标签、不导出、不发布。
- 不复制排序、重命名、水印、标签、发布或导入器的业务代码；模板统计和文案生成只使用当前工作台的交付模块。
- 小红书和 Instagram 是浏览器扩展；头像共享源是后台服务；Live Photo 目前明确显示为 Demo。
- `registry.js` 的版本字段必须和对应源 manifest 一致，契约测试会阻止显示版本漂移。

## 验证

```bash
npm test
npm run package
```

源码和自动测试通过后，还要在真实 Eagle 中打开工作台，确认卡片显示“基本功能”和“版本日志”。本版本已完成本机安装与真实界面验收。

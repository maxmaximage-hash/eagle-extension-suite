# Eagle 工作台

Eagle 工作台是只读的扩展版本总览面板。每张卡片先显示该产品的基本功能，再显示当前版本的重要修复记录。它不执行排序、改名、标签、导入或发布，也不提供容易失效的“打开入口”按钮。

## 设计边界

- 用户界面只显示两段式产品版本 `major.minor`；minor 只从 `0` 到 `9`，例如 `1.9` 之后进入 `2.0`，不会出现 `1.11`，也不会把三段式技术版本显示给用户。
- 工作台自身的 manifest、package、Eagle 安装确认和用户界面统一使用两段式 `1.1`；不会在任何工作台位置显示三段式版本。
- 不复制排序、重命名、水印、标签、发布或导入器的业务代码。
- 不自动扫描当前 Library，不自动改名、不写标签、不导出、不发布。
- 排序、地点标签在媒体智能整理中保持同包但业务状态隔离；水印/隐私/发布属于 MAX Publisher。
- 小红书和 Instagram 是浏览器扩展；头像共享源是后台服务；Live Photo 目前明确显示为 Demo。
- `registry.js` 的版本字段必须和对应源 manifest 一致，契约测试会阻止显示版本漂移。

## 验证

```bash
npm test
npm run package
```

源码和自动测试通过后，还要在真实 Eagle 中打开工作台，确认卡片显示“基本功能”和“版本日志”。本版本已完成本机安装与真实界面验收。

# Eagle 扩展应用

每个可独立安装、运行和交付的 Eagle 扩展使用独立子目录。

- `media-organizer`：媒体智能整理与 Eagle 主程序桥接。
- `online-publisher`：线上展示、水印、隐私打码、字体与发布。
- `web-media-importer`：用户明确触发后，将当前网页已加载的直连图片/视频保存到指定 Eagle 普通文件夹。
- `instagram-post-importer`：从 Instagram 网页将一条帖子的全部图片和视频导入 Eagle。
- `xiaohongshu-post-importer`：从小红书单条笔记整理静态图片并导入 Eagle。
- `live-photo-manager`：以只读组件组管理 Live Photo 配对、预览与恢复锚点。
- `avatar-source-publisher`：将指定头像文件夹发布为版本化、只读的共享资源契约。

# 功能说明

## 媒体智能整理

### 排序层级

排序遵守一条固定优先级：

1. Eagle 原生浏览、选择、预览、右键、导入导出和拖出能力始终保留；
2. 插件自动排序在原生结果之上生成目标顺序；
3. 单张手动拖动保存为“相对位置关系”，覆盖该张素材的自动位置；
4. 排序锁定是最高状态：锁定后保持当前规则与结果，并禁止继续手动拖动；
5. 自动编号和安全改名只在最终顺序确定后执行，并且必须经过预览与确认。

切换拍摄时间升序/降序时，自动部分整体重排，已经保存的手动关系按相对位置重新投影。选择“恢复自动排序”会清除当前视图的手动关系，并立即回到当前插件规则的完整自动顺序。

### 普通文件夹

- 拍摄时间、导入时间、修改时间、文件名等排序；
- 多级排序；
- 手动拖动和完整插入位置反馈；
- 排序锁定；
- 自动编号、编号预览、安全改名、冲突保护和回滚记录；
- 父子文件夹的明确范围治理。

### 智能文件夹

- 对当前 Eagle 查询结果排序；
- 支持多级排序、手动拖动、恢复自动排序和排序锁定；
- 保存的是智能视图自己的顺序，不改来源普通文件夹；
- 不显示、不执行自动编号或自动改名。

### 团队排序同步

插件把规则和手动相对顺序写入与 Library 同级的 sidecar，而不是修改 `.library`。同版本插件在同一 NAS Library 上会自动读取并校验该文件，团队成员无需重新排序。详细行为见 [TEAM_SORT_SYNC.md](TEAM_SORT_SYNC.md)。

### GPS 与元数据标签

- 读取图片 EXIF GPS 和拍摄元数据；
- 在本机离线解析国家、省/州、市、区县等地域；
- 不调用地图 API，不上传坐标或素材；
- 视频 GPS 读取依赖系统 `ffprobe`，缺失时给出明确提示；
- 新安装默认不扫描或改写整库，启用前先建立基线并要求明确确认。

## MAX Publisher

### 水印与本地导出

- 文本或图形水印；
- 字体、字重、字距、行距、颜色、阴影、透明度、旋转、平铺和九宫格定位；
- 水印预设的保存、另存、重命名和删除；
- 按图片质量或目标文件大小导出；
- 同名文件生成新名称或显式覆盖。

### 隐私打码

- 矩形、椭圆区域；
- 模糊或马赛克；
- 多区域强度调整、隐藏预览、撤销、重做和清除；
- 文字标注；
- 可与水印预设组合后再导出。

### 字体库

- 动态读取每台 Mac 实际安装的字体；
- 搜索、显示/隐藏、收藏和分类；
- 缺失字体会明确标记，并使用可用字体降级，不再引用开发者电脑路径；
- 仓库不分发商业字体文件，团队成员需自行获得对应字体许可并安装。

### 线上发布

当前保留 Cloudflare Pages 发布流程作为暂用版本。它是可选能力，需要每位使用者配置自己的 Cloudflare 项目和登录凭据；排序、标签、水印、马赛克和本地导出不依赖它。

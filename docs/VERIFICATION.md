# 验证、升级与回滚

## 三层验收

1. **源码门禁**：语法、单元、模块边界、永久回归、构建和安装包哈希。
2. **安装门禁**：插件 ID、版本、唯一安装来源、宿主兼容性、备份和回滚脚本。
3. **真实 Eagle 验收**：由用户在自己的真实 Library 中观察界面和结果。

自动门禁通过不能替代第三层。

## 安装后最小验收

- Eagle 原生选择、预览、右键、快捷键、导入导出和拖到 Finder 正常；
- 普通文件夹的拍摄时间、多级排序和手动拖动入口存在；
- 智能文件夹有排序和手动拖动，但没有自动编号/改名；
- 团队成员打开同一 Library 后看到已有规则和手动相对顺序；
- GPS 标签页可以先预览，未确认前不写标签；
- MAX Publisher 能打开水印、隐私打码和字体界面；
- 本地导出不修改 Eagle 原图；
- Cloudflare 未配置时只提示缺少配置，不影响本地功能。

## 回滚

安装成功时会打印本次回滚目录。需要回滚时先正常退出 Eagle，再运行：

```bash
./scripts/rollback.sh --backup '<安装器打印的绝对回滚目录>'
```

回滚脚本只恢复两个插件目录，不修改 Library、团队 sidecar、素材或 Eagle 宿主。

## 报告问题

至少提供：

- Eagle 精确版本和 macOS 版本；
- 插件 ID、版本和安装路径；
- 普通文件夹或智能文件夹；
- 实际操作、预期结果、实际结果；
- 不含真实素材和密钥的截图；
- 插件诊断日志中的相关时间段。
